# ♻️ ReThread - Community Clothing Exchange & Swap Marketplace

ReThread is a full-stack sustainable web application designed to reduce fashion waste through peer-to-peer apparel swapping.

## 🚀 Tech Stack

- **Frontend**: React.js, Tailwind CSS, Lucide React Icons, React Router
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas
- **State & Real-time**: Local State & Socket.io
